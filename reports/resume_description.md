# Resume Project Description

## Netflix Movies and TV Shows Analysis
**Technologies**: Python, Pandas, NumPy, Matplotlib, MySQL, Flask, HTML5, CSS3, JavaScript, Pytest, Git

- Engineered an end-to-end data analytics pipeline and full-stack Flask web application analyzing 6,234 titles from the Netflix streaming catalog.
- Cleaned and normalized raw metadata using Pandas, separating composite duration metrics into minutes and season counts, standardizing ISO-8601 dates, and validating primary key integrity.
- Conducted exploratory data analysis on content splits (68.4% Movies vs 31.6% TV Shows), international co-production hubs across 100+ nations, genre hierarchies, and audience maturity ratings.
- Designed relational MySQL 8.0 schemas with 1:N foreign-key normalized tables (`title_countries`, `title_genres`) and authored 10 analytical SQL queries with performance indices.
- Generated 8 production-grade Matplotlib visualizations styled harmoniously with a modern dark-mode aesthetic.
- Developed an interactive Flask web application with 5 responsive routes (`/`, `/analysis`, `/visualizations`, `/sql-queries`, `/about`), client-side table filtering, and query accordions.
- Authored a comprehensive Pytest automated test suite achieving 100% pass rate across 21 unit and integration test cases.
