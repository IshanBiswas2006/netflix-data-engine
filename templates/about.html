Executive Summary

End-to-End Analytics Platform

The Netflix Movies and TV Shows Analysis project was built to deliver an end-to-end demonstration of full-stack data analytics. Spanning data ingestion, reproducible cleaning, mathematical descriptive analysis, relational SQL database modeling, production Matplotlib visualization, and interactive web engineering, the system translates raw, unstructured streaming metadata into empirical business intelligence.

Engineering Lifecycle

Data Pipeline Architecture

Each phase feeds deterministically into the next.

Phase 01

Data Acquisition & Validation

Ingested raw dataset of 6,234 records across 12 features. Preserved original CSV in data/raw/ with automated schema assertions verifying column completeness and 100% unique primary keys.

Phase 02

Reproducible Cleaning

Separated composite duration into distinct numeric fields (duration_minutes for Movies, seasons_count for TV Shows). Parsed human-readable date strings into ISO-8601 dates and extracted calendar dimensions.

Phase 03

Exploratory Analysis

Exploded multi-value comma-separated strings (countries, genres, directors) to calculate mathematically unbiased category frequency rankings without double-counting unique titles.

Phase 04

Relational SQL Modeling

Designed relational database schemas with netflix_titles, title_countries, and title_genres tables. Engineered 10 analytical SQL queries with performance indices and aggregate subqueries.

Phase 05

Data Visualizations

Created 8 standardized Matplotlib charts saved into static/images/charts/. Styled to match the dark UI theme with high-contrast typography, clear labels, and zero synthetic data.

Phase 06

Flask Application & UI

Developed lightweight Flask web server serving 5 dedicated Jinja template views. Integrated custom typography (Tanker, Space Grotesk, Inter), sticky frosted header, and responsive layout breakpoints.

Methodology

Dataset Limitations

  • Directorial information is unlisted for 31.58% of entries, predominantly episodic TV shows.
  • Streaming viewership metrics, box office earnings, and viewer ratings (e.g. IMDb/Rotten Tomatoes) are not included in the raw catalog schema.
  • Date added timestamps reflect digital library availability on Netflix, not theatrical release.
Roadmap

Future Enhancements

  • Automated ingestion via external streaming metadata APIs (TMDB, OMDb).
  • Interactive client-side filtering by genre, release decade, and country of origin.
  • Sentiment analysis of textual synopses using natural language processing (NLP).
